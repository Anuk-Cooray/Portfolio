# Anuk Cooray - Personal Portfolio Web Application

A modern, responsive, and sleek personal portfolio web application built for **Anuk Cooray** (Business Analyst & Associate Project Manager | IT Undergraduate).

## 🚀 Live Preview & Features

- **Sleek Dark-Mode Aesthetic**: Obsidian slate backgrounds (`#07090e`), Glassmorphism cards with backdrop blur, glowing borders, and electric blue & emerald accents.
- **Interactive Constellation Canvas**: HTML5 Canvas particle/mesh network that dynamically reacts to cursor movements.
- **Hero Section**:
  - Live availability status pill ("🟢 Available for Opportunities").
  - Role overview & tagline.
  - CTAs: "View Projects", "Download CV", and "Contact Me".
  - Direct links to LinkedIn, GitHub, and Email.
  - Interactive profile card with animated halo ring, badges, and floating statistic cards.
- **About Me**:
  - Narrative highlighting IT degree at SLIIT, industry experience at Arimac Digital, and SDLC / Agile expertise.
  - 4 Pillars: Agile Delivery, Requirements Engineering, QA & Automation, Stakeholder Management.
- **Core Competencies & Skills Matrix**:
  - *Business Analysis & Management*: Agile/Scrum, Requirements Elicitation (SRS), User Stories, Trello & Confluence, Process Mapping (BPMN), Wireframing (Figma).
  - *Technical & Data Toolkit*: SQL & Relational DBs, Test Automation (Playwright TypeScript), MERN Stack basics, Git/GitHub, System Architecture, REST APIs.
  - Proficiency indicators with animated percentage progress bars.
- **Featured Projects Showcase**:
  - **Campus Connect**: Project Management, SRS Modeling, BPMN, and Agile backlog management.
  - **SwiftTranslator Automation Suite**: Playwright TypeScript E2E test automation framework with CI/CD integration.
  - **Fashion Fiesta**: Full-Stack MERN e-commerce web platform.
  - **Interactive Modal**: Deep-dive case study modal with Background, Problem Statement, Key Solutions/Deliverables, Business Impact, and Tech Stack tags.
- **Experience & Education Timeline**:
  - *Trainee – Business Analysis & Project Management* | Arimac Digital (Active pulsing node)
  - *BSc (Hons) in Information Technology* | SLIIT
  - *Secondary Education* | Isipathana College - Colombo 05
- **Curriculum Vitae (CV) Engine**:
  - Built-in interactive CV viewer with instant "Print / Save as PDF" functionality styled for clean print formatting.
- **Contact & Footer**:
  - Interactive contact form with real-time validation (Name, Email, Subject, Message) and animated toast feedback.
  - Quick contact information card.
  - Back to Top floating button with smooth scroll.

---

## 🛠️ Tech Stack & Architecture

- **Markup**: Semantic HTML5 with ARIA accessibility roles.
- **Styling**: Modern CSS3 (Custom CSS design system, Glassmorphism, CSS Grid, Flexbox, Keyframe Animations, Print Media Stylesheet).
- **Typography**: Plus Jakarta Sans, Inter, JetBrains Mono via Google Fonts.
- **Interactivity**: Pure Vanilla ES6+ JavaScript (Zero external dependencies, lightning-fast execution).
- **Graphics & Icons**: Custom inline SVG graphics and HTML5 Canvas particle physics.

## 🌐 How to Run Locally

Simply double-click `index.html` or open it in any modern web browser (Chrome, Edge, Firefox, Safari).

Alternatively, if you use VS Code, you can use the **Live Server** extension to preview it live.

---

## 🚀 Deployment Options

### 1. GitHub Pages (Free & Recommended)
1. Push this repository to GitHub (`github.com/Anuk-Cooray/portfolio`).
2. Go to **Settings** > **Pages**.
3. Under **Branch**, select `main` (or `master`) and `/root`, then click **Save**.
4. Your portfolio will be live at `https://Anuk-Cooray.github.io/portfolio`.

### 2. Vercel or Netlify
1. Connect your GitHub repository to Vercel/Netlify.
2. Deployment runs automatically with zero configuration needed.
