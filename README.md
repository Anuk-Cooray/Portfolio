# Personal Portfolio Web Application

A responsive personal portfolio website showcasing my work in Business Analysis, Project Coordination, and Quality Engineering.

## Overview

A lightweight, dependency-free portfolio built with semantic HTML, modern CSS, and vanilla JavaScript. Designed with a dark glassmorphic theme, responsive layouts, and interactive UI elements.

## Features

- **Interactive Canvas:** Dynamic particle/mesh background built with HTML5 Canvas.
- **Project Case Studies:** Modular showcase cards with modal deep-dives highlighting problem statements, system architecture, and deliverables.
- **Skills Matrix:** Categorized breakdown covering requirements engineering, Agile workflows, SQL, and Playwright test automation.
- **Experience Timeline:** Visual career and education roadmap.
- **In-Browser Resume Viewer:** Dedicated view optimized for both on-screen reading and clean print/PDF export.
- **Contact Form:** Client-side input validation with custom feedback states.

## Tech Stack

- **Frontend:** HTML5, CSS3 (CSS Grid, Flexbox, Custom Properties)
- **Scripting:** Vanilla JavaScript (ES6+)
- **Typography:** Plus Jakarta Sans, Inter, JetBrains Mono
